# ESP32 Wi-Fi 控制台

App 默认使用 Wi-Fi 控制台，配合 `hardware/flash.sh --cloud` 固件。模型请求、
画面解码和 USB HID 动作在 ESP32 上执行。App 负责手机配置、下发任务、查看状态和停止任务；不显示手机截图。
Mac 网页负责实时监控和指针校准。切换到其他 App 不会停止板子上的任务。

## 连接与使用

1. ESP32 与 iPhone 连接同一路由器，允许局域网设备互通。ESP32 使用 2.4 GHz。
2. App 启动先显示登录页，输入本地控制令牌并点击“登录控制台”。只有收到板子
   返回的有效鉴权状态后才进入 Dashboard；错误令牌、超时或无效响应都不会进入。
   默认地址为 `iphone-agent.local`，通过 mDNS 自动解析当前 IP；局域网不支持 mDNS
   时可改填 IP。令牌可通过 USB 串口命令 `1 agent token` 获取，与云端 API 密钥不同。
3. 第一次连接时允许 App 的“本地网络”权限。若拒绝过，在 iOS 设置中重新开启。
4. 控制中心 → 屏幕镜像 → ESP32 Agent。设备状态以完成进度和状态卡片显示，
   每个卡片都可点击查看分步骤指引；未连接、待配置和画面异常都有文字与图标提示。
   镜像和画面解码需分别就绪，不能只凭镜像已连接判断可以执行任务。
5. ESP32 原生 USB 接到 iPhone 的 USB 主机转接器，开启辅助触控。
   iPhone 13 使用 Lightning USB 主机/相机转接器；普通充电数据线不能代替。
   “已检测到 USB”不能区分 Mac 与 iPhone；点击 USB 卡片，按接线图操作后确认接到手机。
   接线确认通过 `/api/phone-host` 同步到 ESP32，网页读取同一状态。
   板子重启或 USB 断开后确认失效；App 重连会重新读取板子的真实状态。
6. 在 Mac 打开 `http://iphone-agent.local/`，登录后点击监控区的“指针校准”。
   等待真实指针停稳，再点击网页画面里的指针中心；App 自动同步校准结果。
   更改指针速度或更换手机后重新校准。校准时不要旋转屏幕。
7. 在“任务”区点击示例即可启动，也可以输入自己的任务。发送后离开本 App，保持手机解锁和屏幕镜像开启。
   “停止任务”在请求云端期间仍可使用；App 只有收到板子确认后才显示已停止。

App 在前台每 3 秒读取状态，显示真实 Wi-Fi 名称、IP 和更新时间，不请求或展示截图。
网页将监控画面放在主要位置，默认约每 5 秒刷新（网页可选 3／5／10 秒），支持暂停、手动刷新和全屏；
标签页在后台时暂停截图请求，返回后继续。任务运行期间仍持续刷新。
连接失败或超过 8 秒未收到有效状态时，清除旧状态并显示连接中断；恢复后重新读取。
令牌失效返回登录页，设置菜单可退出登录。冷启动需要输入令牌，切到后台再返回保留
当前会话并重新检测。退出登录不停止板子正在运行的任务。没有可用画面、已确认的手机 USB 接线或校准数据时，
点击示例或发送任务会打开第一项未完成配置的指引，保留已选择的示例。
完成后可直接在指引页启动该示例，固件也会独立校验执行条件。任务限制及支持的动作见
[`hardware/tools/README.md`](../hardware/tools/README.md)。

App 提供 12 个任务示例：Wi-Fi、电池、存储空间、系统版本、闹钟、世界时钟、
今日日程、天气、显示设置、语言地区、蓝牙状态和屏幕使用时间；默认展示前三个，
点击“查看全部 12 个任务示例”展开。示例只读取信息，不修改设置或发送消息。
网页另有“读懂当前屏幕”，共 13 个示例；该示例不依赖 USB 或校准。
“检测云端连接”仅发送文本请求，不发送 HID 动作。

示例源文件为 `shared/task-examples.json`，修改后运行
`node hardware/tools/task_examples.cjs`，同步生成 Swift 与嵌入网页的任务目录。

## 开发与个人安装

使用 XcodeGen 从 `ios/project.yml` 生成项目。个人开发设备可在忽略版本控制的
`ios/Config/Local.xcconfig` 中设置签名信息。控制台不再使用预置令牌或旧 Keychain
记录自动登录；令牌只在当前 App 会话内使用，退出登录后清除。登录成功时保存
设备地址，下次可修改；新的安装默认使用 `iphone-agent.local`。

云端 URL、模型和 API 密钥的初始值来自 ESP32 的 `secrets.h`。
在 App 右上角“设置 → 云端模型配置”（或“云端模型”区的同名入口），
可读取并修改板子的 API 地址、模型名称和 API Key。网页“模型配置”入口共用
同一份板子配置，保存后立即生效，并保存在 NVS，重启后仍有效。
填写完整的 HTTPS Chat Completions 地址；密钥保存后不回显，留空保留已有密钥。
“保存并测试连接”先保存再进行文本连接测试，图片支持请在网页使用“读懂当前屏幕”验证。
任务运行期间不能保存配置；API 校验或持久化失败时保留原有配置并显示错误。
新控制台不读取旧版
iPhone LLM 配置，也不启动 BLE 接收器或 iPhone 端 AgentLoop。旧实现保留在源码中。
任务与状态快捷指令已转发到板子；旧的“运行已保存意图”入口会提示打开控制台。

局域网 HTTP 通过 `NSAllowsLocalNetworking` 配置启用；客户端仅接受私网 IPv4
地址或 `.local` 名称，并拒绝重定向，避免把控制令牌转发到其他地址。
`Documents/board-connection.json` 记录最后一次连接结果，便于真机安装后核对，
不记录令牌、任务、截图或云端密钥。

验证：`CloudBoardTests` 覆盖地址边界、鉴权、请求格式、错误传播、执行前提、
示例的配置跳转、USB 接线确认在掉线与重启后的失效，共享接线确认及失败处理，以及模型配置读取、
空白密钥保留、密钥替换和保存错误传播，以及登录验证、退出登录、过期状态清除、
网络中断恢复和 401 返回登录页。
解码吞吐量与实际手机 HID 操作仍需要连接真机验证。

## 一键打开 iPhone 设置

配置卡片与相关按钮统一使用系统设置跳转：本地网络权限打开本 App 的设置页；
USB 卡片在辅助触控未开启时打开辅助触控，已开启时打开设备列表。USB 与校准
指引中也提供对应入口。辅助触控状态直接读取 iOS，返回 App 后自动刷新并重读
板子状态。iOS 26 及以上使用 `AccessibilitySettings.openSettings(for:)` 的
`.assistiveTouch` / `.assistiveTouchDevices`；旧版或不支持的设备显示准确的手动路径。
Wi-Fi 系统页和控制中心屏幕镜像没有官方直达入口，镜像保留两步指引；指针校准
是 ESP32 的操作，在 Mac 网页监控区执行；点击 App 的校准指引不会发送 HID。

接口依据：[Apple 设置跳转](https://developer.apple.com/documentation/accessibility/accessibilitysettings/opensettings(for:))、
[App 设置页](https://developer.apple.com/documentation/uikit/uiapplication/opensettingsurlstring)。
