# 使用手册

[返回导航](README.md) · [安装](install.md)

## 每次开机

ESP32 自动连接已配置的 Wi-Fi。手机加入同一 LAN，保持解锁，开启“屏幕镜像 → ESP32 Agent”。
通过 `http://iphone-agent.local/` 或 iPhone App 输入控制令牌登录。

Wi-Fi 连接不依赖登录。控制台令牌也不在每次重启时随机更换；正常重启会保留 NVS 中的令牌和模型配置。
但**手机 USB 接线确认在板子重启或 USB 断开后会失效**，需要重新核对。

## 两个控制端的分工

| iPhone App | 网页 Dashboard |
|---|---|
| 本地网络、镜像、辅助触控等配置指引 | 手机监控画面，默认 5 秒更新 |
| 点击状态卡片查看需要处理的步骤 | 任务时间线、输入详情、模型公开观察与动作参数 |
| 提交 Goal、12 个只读示例、停止 | 提交 Goal、13 个示例、停止、指针校准 |
| 修改板上模型配置 | 修改同一份板上模型配置 |
| 不显示自身被控画面 | 不提供需要在手机完成的配置引导 |

发出任务后离开 iPhone 控制 App，让目标 App 显示在前台。板子负责循环，不需要手机停留在控制台。

## 状态自检

- **设备连接**：已鉴权并读到新状态；显示 Wi-Fi、IP 和更新时间。
- **屏幕镜像**：AirPlay 正在接收，不等同于画面已经可解码。
- **画面解码**：有新 JPEG；旧图或错误不作为可执行依据。
- **手机 USB**：既需要 USB 枚举，也需要用户确认真实接到手机。
- **指针校准**：已保存相对鼠标移动与画面坐标的对应关系。

App 可直接打开它自身的设置页；在支持的 iOS 版本中可打开辅助触控相关设置。
Wi-Fi 页面和控制中心镜像没有可依赖的官方直达入口时，会显示具体手动路径，不承诺“所有系统页都能一键跳转”。

## 指针校准

1. 确认板子原生 USB 已从 Mac 移到手机主机转接器。
2. 开启辅助触控并确认手机屏幕上出现真实指针。
3. 网页监控区点击“指针校准”，开始后等待指针停稳。
4. 点击“立即刷新”，在**手机画面内**点击指针中心；不要点黑边。
5. 查看校准成功状态。更换手机、改变指针速度或屏幕方向后重新校准。

校准会实际移动鼠标。不要在 USB 接着 Mac 时确认手机主机或点击开始校准。

## 提交一个 Goal

建议先用“查看 Wi-Fi 名称”“查看电池状态”等只读任务。也可明确输入：

> 打开设置的 Wi-Fi 页面，告诉我当前连接的网络名称。只查看，不修改设置；读到后停止。

按“发送任务”后，控制台显示收到的原始 Goal。每轮依次：

1. 读取新画面和之前的动作反馈。
2. 显示当前观察、进展摘要、子目标、动作选择说明与预期变化。
3. 派发一个动作，记录 HID 确认。
4. 等待动作后新的稳定画面，判断是否达到预期。
5. 继续调整；达到目标时再用新图复核一次。

公开的“选择说明”是简短可读解释，不是模型内部思维链。
“命令已确认”不代表任务完成；“候选完成”也不等于已经通过复核。

## 任务示例

| 示例 | 主要用途 |
|---|---|
| 读懂当前屏幕（网页） | 只识图，不发 HID，适合最初联调 |
| 查看 Wi-Fi 名称 | 打开设置并读取当前网络 |
| 查看电池状态 | 查看电量、低电量模式 |
| 查看存储空间 | 查看已用空间与容量，不删除内容 |
| 查看系统版本 | 读取机型与 iOS 版本，避免设备标识 |
| 查看已有闹钟 | 查看启用的闹钟，不新增修改 |
| 查看世界时钟 | 读取已添加城市，不调整列表 |
| 查看今日日程 | 查看日历，不增删事件 |
| 查看今日天气 | 查看已有城市，遇权限提示停止 |
| 查看显示设置 | 查看外观和亮度，不拖动滑块 |
| 查看语言与地区 | 只读取当前配置 |
| 查看蓝牙设备 | 只读取状态，不连接或配对 |
| 查看屏幕使用时间 | 查看已有统计，未启用则报告 |

示例仍需满足真实设备前提。点击示例即启动；配置不全时 App 会给出第一项缺失条件的引导。

## 网页监控与执行记录

- 默认 **5 秒**刷新；文本细节优先，可选 3 / 10 秒，支持暂停、手动刷新、全屏。
- 后台标签页暂停截图；返回后继续。指针校准期间暂停自动刷新以稳定点击位置。
- 分辨率、帧龄、传输和板内处理耗时帮助判断等待来自哪里。
- 帧龄从数据到达 ESP32 算起，不是手机到浏览器的总延迟；低刷新率自然会增加显示等待。
- “跟随最新”可以关闭，方便阅读之前的记录。执行日志最多 48 条，较早记录会释放，长内容可能截断。
- 网页显示的是灰度画面。清晰度受实际输入分辨率和 8 MB PSRAM 限制，不是手机原生高清串流。

## 配置云端模型

网页“模型配置”或 App“设置 → 云端模型配置”填写完整 HTTPS Endpoint、模型名和 API Key。
Key 保存后不回显；留空表示保留已有 Key。两端读写同一份 NVS 配置，重启保留。

“保存并测试”先保存，再发纯文本测试。模型不支持图片时，文本测试可能成功而视觉任务失败；用网页“读懂当前屏幕”验证实际图像能力。
任务或模型请求未结束时，配置更新会被拒绝。不同服务商的模型名称由服务商决定，不假定所有 Chat Completions 模型都能看图。

## 停止、暂停与恢复

- 点“停止任务”，等控制台确认。旧模型响应之后返回也不能继续发动作。
- 当前已发出的网络请求可能直到超时才释放；这段时间新任务/配置可能仍提示忙。
- 卡住、断开、新帧缺失、结果不确定或达到上限会暂停。查看原因、修复条件，然后重新提交 Goal。
- 当前没有跨重启的任务恢复或持久回放。新 Goal 会清空上次短期记忆和记录。
- 退出网页登录或退出 App 会话**不会自动停止**已经在板上运行的任务；需要停止时先点停止。

## 常见问题

| 现象 | 检查与处理 |
|---|---|
| `.local` 打不开 | 使用路由器 DHCP 列表或串口里的 IP；确认 mDNS/客户端互通，关闭访客隔离 |
| 网页可打开但状态看不到 | 输入本板控制令牌；静态网页可公开读取，真实状态接口需要鉴权 |
| Wi-Fi 待连接 | 看串口状态；检查 2.4 GHz SSID、密码、信号和路由器限制；不是靠登录触发联网 |
| 只充电，没有鼠标 | iPhone 13 需要 Lightning USB 主机/相机适配器；普通 Lightning 充电线不提供所需主机连接 |
| USB 已连接但无法启动 | 核对 USB 主机是否真是手机、接线确认是否因重启失效、是否完成校准 |
| 镜像连接但没有 JPEG | 解码失败或帧已过期；重连镜像，查看视频诊断；不要把旧画面当实时 |
| 画面残影 | 使用当前参考帧修复固件；重新连接镜像以建立新会话；仍异常时保存本地诊断，不公开私人画面 |
| 图像更新慢 | 先区分网页 5 秒间隔、板内处理和模型等待；把刷新拉高不一定改善根因 |
| HTTP 401 | 区分控制台 401 与云端 401；前者查控制令牌，后者查模型 API Key |
| TLS 等待网络时间 | 检查路由器 DNS、互联网与 SNTP；证书验证依赖正确时间 |
| 模型反复输出错误格式 | 查看时间线和 Endpoint/model；模型需按当前 `SYSTEM` 返回一个 JSON 动作，有限重试后会暂停 |
| 中文输入不工作 | 当前 HID `type` 只支持 ASCII；不是完整中文输入法自动化 |
| 每次 IP 变化 | 正常 DHCP 行为；用 `.local` 或路由器 DHCP 保留 |
