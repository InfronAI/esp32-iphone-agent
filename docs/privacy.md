# ESP32 Agent 数据与隐私说明

更新：2026-10-24。适用于本仓库当前 `--cloud` 模式；旧 iPhone Agent 的数据路径不同。

## 当前路径

- iPhone 通过局域网 AirPlay 把屏幕发送给 ESP32。板子在内存里解码并生成灰度 JPEG。
- 执行视觉任务时，ESP32 把 Goal、截图、近期动作摘要发给用户配置的 HTTPS 模型服务；服务商的数据政策适用于这些请求。
- 网页通过局域网 HTTP 读取截图、任务记录和状态。控制令牌提供访问控制，但 HTTP LAN 传输本身没有 TLS 加密。
- iPhone App 当前只负责配置、提交任务与读取状态，不显示手机截图，不执行旧的 iPhone 端 AgentLoop。
- API Key 和控制令牌保存在 ESP32 NVS；当前默认构建没有启用 NVS 加密。Key 不通过配置读取接口回显。
- 当前任务、最新 JPEG 和最多 48 条执行事件主要保存在 PSRAM，新任务或断电会清空。调试模式和人工捕获可能在电脑上留下串口日志与视频。
- App 只在当前会话保留控制令牌；网页可选择在 sessionStorage 记住当前会话。退出登录不自动停止板上的任务。

仓库没有为当前模式配置开发者托管的数据收集服务器。使用自己的模型 Endpoint 时，应自行确认其访问权限、数据保存和费用。
不要提交 `secrets.h`、个人 `Local.xcconfig`、NVS dump、含凭据的固件、真实设备日志或私人画面。

## 旧实现

`ios/` 中保留旧版手机端 Agent、回放、日志导出和 Keychain 代码；它们不是当前默认 Wi-Fi 控制台的主要运行路径。
如果切换回旧版，应重新核对对应功能的数据行为，不能把当前 PSRAM 生命周期套用到旧版手机运行档案。

## 演示素材

公开 Demo 的手机屏幕与任务响应由脚本生成，不含开发设备的实际 Wi-Fi 名称、API Key、控制令牌或私人屏幕录像。
